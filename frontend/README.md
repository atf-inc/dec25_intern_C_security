# ATF CyberX - Frontend

React + TypeScript + Vite frontend for ATF CyberX.

## Setup

```bash
npm install
```

## Development

```bash
npm run dev
```

The app will run on http://localhost:3000

## Build

```bash
npm run build
```

## Features

- Phishing Email Detection
- Voice Deepfake Analysis
- Scan History (Coming Soon)

## Tech Stack

- React 18
- TypeScript
- Vite
- React Router
- Axios
